# Ultima Online Customization Tools

This repository will eventually host a suite of utilities for editing various Ultima Online client resources.
The table below outlines the planned tools and the assets they target.

| Tool | Description | Asset Files |
| --- | --- | --- |
| Art Asset Studio | Import, export, and edit item and land art tiles. | `art.mul`, `artLegacyMUL.uop` |
| Gump Designer | Build and modify user interface gumps. | `gumpart.mul`, `gumpartLegacyMUL.uop` |
| Map Maker | Assemble world maps and static objects. | `mapX.mul`, `staticsX.mul` |
| Tile Data Manager | Adjust tile properties such as flags, names, and weights. | `tiledata.mul` |
| Multi Builder | Create multi-part structures like houses or boats. | `multi.mul`, `multi.idx` |
| Animation Composer | Organize animation frames and directions for creatures. | `animX.mul` |
| Texture Atlas Editor | Modify large terrain and texture atlases. | `texmaps.mul`, `texmaps.uop` |
| Sound Packager | Replace or add sound effects and music. | `sound.mul`, `music/` |
| Hue Palette Editor | Edit color palettes used for dyeing and lighting. | `hues.mul` |
| Localization String Manager | Update in-game text entries. | `cliloc.*` |
